ABSTRACT

Deep learning models like DLoc achieve sub-meter accuracy in indoor WiFi localization by learning a mapping from Channel State Information (CSI) to spatial heatmaps of probability over a floorplan. However, the large size of DLoc - 16.5 million parameters - prevents its use on the edge devices, such as IoT gateways, smartphones, or access points themselves. In this thesis, we investigate whether DLoc’s accuracy can be achieved with a much lighter model. We compress DLoc by training a family of lightweight models: MobileNetV2, a minimal TinyCNN, a MobileNetV2 encoder with U-Net skip connections, and a state-space (Mamba) model. Each model is trained both as a standalone deep learning model, but also as a “student” model distilled from the DLoc teacher. Each of these models is evaluated along five dimensions: accuracy, robustness to signal degradation (access point dropout, Gaussian noise, signal attenuation, and spatial blur), cross-session generalization, statistical reproducibility, and computational efficiency. The best model, a MobileNetV2 encoder with U-Net skip connections, reduces the median error from 0.933 m (DLoc) to 0.640 m - a 9.5% improvement - yet requires only 2.41 million parameters (6.8x fewer) and 56x fewer floating-point operations than the teacher. Furthermore, when evaluated under the same leave-one-session-out protocol as the original DLoc paper, the MobileNetV2-UNet model reaches the same accuracy as DLoc on one fold of the cross-session validation, and remains within 0.1 m of the DLoc accuracy on the other folds. Knowledge distillation was mainly beneficial to robustness to Gaussian noise (improving the robustness by a factor of 3.4), but only benefitted models with sufficient capacity relative to the data; smaller models that were distilled actually suffered in accuracy with the use of knowledge distillation. Together, these results indicate that it is possible to achieve accurate localization using lightweight models, and that both architectural and training-based design elements help to resolve accuracy and robustness issues.

Keywords: WiFi indoor localization, channel state information, knowledge distillation, model compression, MobileNetV2, U-Net skip connections, robustness, cross-session generalization, edge deployment.

CHAPTER 1 - INTRODUCTION

1.1 Background and Motivation

Indoor localization is an essential task for many emerging technologies and applications. Examples of those applications range from the tracking of assets within large warehouses, the tracking of patients within a hospital, augmented reality applications, automated robotic systems, and various location-aware services within large public buildings. Outside of these buildings, the Global Positioning System (GPS) is typically utilized to determine the location of an object to within a few meters of its true location. GPS is, however, ineffective within indoor environments; the GPS signals are reflected and attenuated by the walls and ceilings that surround indoor locations.

An alternative technology to WiFi signals has been used for indoor localization for the past two decades.  Technologies that use WiFi, Bluetooth, ultra-wideband signals, and inertial sensors have been explored as alternatives to GPS for indoor localizing objects or individuals.

WiFi technology has been the focus of much of the research on indoor localizing technology. Why WiFi signals have been of interest for indoor localization is because WiFi infrastructure is already installed throughout most buildings. Furthermore, the WiFi hardware that is installed upon each of these access points (APs) provides Channel State Information (CSI). CSI is information that describes the attenuation and phase of each of the subcarriers that are emitted by each of the APs. Because the attenuation of the signals to the WiFi devices is related to the distance between each of those devices, the CSI information can theoretically allow for the localizing of an object to within sub-meter distances of its actual location.

In order to determine its location within a floorplan, DLoc utilizes techniques similar to image translation. The CSI from each of the APs is transformed into a multi-channel image. A deep learning model with an encoder-decoder structure is trained to recognize the CSI from each AP and to output a spatial heatmap indicating the probability of the location of the object within the building. As a result, DLoc was able to achieve sub-meter accuracy in its localization results [cite: DLoc].

The accuracy that DLoc achieves is, however, at the cost of high model complexity. DLoc contains 16.5 million parameters that are required to perform the localization. Thus, DLoc is not beneficial for deployment upon edge devices such as IoT gateways and smartphones, as their computational and memory resources are limited.

1.2 Problem Definition

In order for WiFi localization models to be beneficially deployed into indoor environments, the models must be accurate, robust, and efficient. While DLoc is accurate in localizing objects within a floorplan, it is not efficient in relation to its resource requirements for deployment to edge devices. Thus, a method of compressing DLoc such that an accurate, efficient model can be deployed upon edge devices is required. Furthermore, such a method of compression comes with several problems that must be resolved.

The high parameter count for models like DLoc indicates that the model has a high cost for deployment upon edge devices. Furthermore, it is not known how small of a model is required to still achieve accurate localization with DLoc.

Accuracy is likely to be lost if a model is compressed to reduce its parameter count. Thus, an accurate model that is compressed for efficiency is desired.

The signals that are used for WiFi localization are likely to be degraded in their transmission from AP to WiFi device. Thus, localization models have to be robust against signal degradation.

The indoor environments in which the objects to be localizable are moving within may change over time. Thus, the localization models must be able to generalize to changes in the indoor environment.

The results of training a model are dependent upon the random initialization of its weights. Thus, the localization model must exhibit reproducibility in its results across different random initializations of its weights.

Thus, the problem that is to be solved is how to replace the DLoc model with a model that is an order of magnitude in size yet maintains its localization accuracy, and additionally addresses the robustness and generalization of the model to changes in the indoor environment.

1.3 Project Objectives

The goal of this project is to design, train, and evaluate a family of lightweight models that are compressed from the DLoc model, and to gain an understanding of the various mechanisms that affect their accuracy and robustness. The specific goals of this project are:

To compress the DLoc model by training lightweight models (MobileNetV2, a minimal TinyCNN, and a state-space Mamba model) to behave similarly to the teacher DLoc model; this will allow to measure the accuracy of models that have reduced parameter counts.

To improve the accuracy of the models by using architectural designs (such as U-Net skip connections) to allow for the model with fewer parameters to surpass the accuracy of teacher DLoc.

To characterize the robustness of models to signal degradation such as AP dropout, noise, signal attenuation, and spatial blur.

To measure the generalization of models across different sessions of WiFi devices within the indoor environment.

To validate the results of the experiments that were performed on the models, as well as to quantify the computational efficiency of each of the models tested.

The remainder of this thesis is dedicated to reviewing relevant literature on indoor localization, knowledge distillation, efficient deep learning models, and robustness to signal degradation. Following that literature review is a description of the DLoc model, the WILD dataset, and each of the models to be tested in this thesis. Chapter 4 describes the details of how each of the models was implemented. Chapter 5 describes the results of testing each of the models, and Chapter 6 draws conclusions from those results. Finally, Chapter 7 proposes future work related to this thesis.

2.1 WiFi Indoor Localization

Indoor localization has been studied as a technology for the past two decades, mainly as a result of the fact that GPS signals do not effectively reach individuals that are within indoor environments. Technologies like WiFi, Bluetooth, and other technologies have been investigated as potential replacements for GPS signals within indoor environments.

WiFi localization is one of the most studied technologies for indoor positioning. This technology uses the infrastructure that is already installed in most buildings. Each WiFi access point (AP) continuously emits signals that contain Channel State Information (CSI). CSI contains information about the strength of the signal to each of the subcarriers that are continuously transmitted by each AP. The strength of the signal to each of the subcarriers is related to the distance between the AP and the WiFi device; thus, by measuring the CSI of each AP, localization of the WiFi device can be performed to within sub-meter accuracy [cite: DLoc]. Furthermore, the method was implemented as a deep learning model named DLoc that achieved sub-meter median accuracy [cite: DLoc]. In addition to this model, the dataset (named WILD) upon which it was trained was also published [cite: WILD].

Relevance to this work. DLoc and the WILD dataset will be utilized in this work. Thus, their relevance to this work is immediately apparent.

2.2 Knowledge Distillation

Knowledge distillation (KD) was introduced by Hinton et al. [cite: Hinton-KD] as a technique by which a small “student” neural network could be trained to learn the same behavior as a much larger “teacher” network. Knowledge distillation techniques train the student not only to minimize the difference between its predictions and the “ground truth” labels of the training data, but also to minimize the difference between its “soft” predictions and the soft labels of the teacher. The soft labels of the teacher are typically generated by applying a softmax activation function to the teacher’s output logits; this transforms the teacher’s raw outputs into a probability distribution over the possible classifications. In classification problems, the predictions and labels of each training example are the one-hot encoded label of the true classification. In contrast, the “soft” labels contain probabilities that each class is the true classification of the example. These probabilities provide information that the teacher network has learned about the similarities between each of the classes; thus, utilizing these probabilities as the target of the student enables the student network to learn these similarities as well. Distillation has been applied to various classification problems, but it has also been applied to problems in which the target of the deep learning models is not a classification problem; thus, the benefit that the soft labels provide for classification problems is different from that in which their benefits are utilized.

Relevance to this work. The relevance of this literature to this thesis is that deep learning models use knowledge distillation to enable a student model to learn the same behavior of a teacher model as deep learning models whose behavior was established through deep learning; therefore, utilizing knowledge distillation techniques to train a student model will allow the student model to learn localization of objects to within the same accuracy of the teacher model.
